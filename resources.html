Manage Materials

For admins: all training materials and quizzes are managed from files in this project. Change them there and the whole site updates. (To add handy links, use the Resources menu instead.)

How to add or change a material

  1. Open the file data/resources.js.
  2. Link, Google Slides or Drive: paste the URL into the src field. In Google, set sharing to "Anyone with the link can view" and add public: true so it opens directly on the site.
  3. PDF/PPT files: put the file in the files/ folder, then set src (for example files/payroll-mt.pdf) and type ("pdf" or "ppt").
  4. Set updated to the date, save, then upload to GitHub.

A material without a file is automatically marked Waiting for file on the site.
