Kelola Resource

Semua materi diatur dari satu file. Ubah di situ, seluruh web ikut ter-update.

Cara menambah atau mengubah materi

  1. Buka file data/resources.js.
  2. Link, Google Slides, atau Drive: tempel URL pada field src. Set di Google: "Anyone with the link can view".
  3. File PDF/PPT: taruh file di folder files/, isi src (contoh files/payroll-mt.pdf) dan type ("pdf" atau "ppt").
  4. Isi updated dengan tanggal, simpan, lalu upload ke GitHub.

Materi tanpa file otomatis ditandai Menunggu file di web.
